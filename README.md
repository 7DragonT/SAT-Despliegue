# Sistema de Alerta Temprana (SAT)


El Sistema de Alerta Temprana (SAT) es una herramienta de apoyo para las instituciones, la cual busca identificar preventivamente a estudiantes que pueden tener factores de riesgo académico.

Para su uso, la herramienta consta de un cuestionario funcional y ayudas de selección multiplex asociadas al perfil de cada estudiante.

> El resultado es una herramienta de apoyo para la orientación académica y no reemplaza la valoración profesional del docente u orientador.

## Ingreso al sistema

1. Abra la aplicación.
2. Ingrese la contraseña de acceso.
3. Seleccione la opción correspondiente al tipo de evaluación que desea realizar.

## Evaluación de un estudiante

Para realizar una evaluación individual:

1. Ingrese la información solicitada del estudiante.
2. Verifique que los datos estén correctamente diligenciados.
3. Ejecute la evaluación.
4. Revise el resultado de probabilidad de riesgo y factores a atender o reforzar.
5. Si lo desea puede descargar un PDF de la ejecución y su resultado.

Importante: 
* El resultado debe utilizarse como apoyo para orientar la revisión del caso y no como una decisión definitiva sobre el estudiante.
* La herramienta mantiene total anonimato de los estudiantes con el fin de garantizar su privacidad.


## Evaluación de varios estudiantes

La aplicación permite procesar varios estudiantes mediante un archivo CSV.

1. Descargue la plantilla CSV disponible en la aplicación.
2. Complete la información de los estudiantes.
3. Guarde el archivo en formato CSV.
4. Cargue el archivo en la sección de procesamiento masivo.
5. Verifique la información mostrada antes de procesar los registros.
6. Ejecute el procesamiento.
7. Revise los resultados obtenidos.
8. Descargue el archivo CSV con los resultados.

Se recomienda utilizar la plantilla proporcionada por la aplicación para evitar errores en los nombres o formatos de las variables.

## Uso responsable

La información generada por el sistema debe utilizarse únicamente como apoyo a la orientación académica.

Se recomienda mantener la confidencialidad de la información de los estudiantes y evitar utilizar el resultado para etiquetar, excluir o tomar decisiones definitivas sobre un estudiante.

Ante cualquier resultado, la decisión y las acciones de acompañamiento corresponden al personal responsable de la orientación educativa.

## Instalación local

Para ejecutar la aplicación en el pc de la institución:

1. Descargue el repositorio del proyecto.
2. Extraer o descomprimir la carpeta.
3. Ubique el archivo ejecutar.bat o ejecutar.
4. Haga doble clic sobre ejecutar.bat.
5. El sistema creará automáticamente el entorno necesario e instalará las dependencias.
6. La aplicación se abrirá automáticamente en el navegador.

Se recomienda contar con una instalación de Python en el equipo para realizar la ejecución local.
